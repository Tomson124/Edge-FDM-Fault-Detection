# ShuffleNetv2 Training and Evaluation
This directory contains code for training and evaluating a ShuffleNetv2 model for 3D fault detection tasks. The implementation seen in '[main.ipynb](main.ipynb)' is setup to train the most performant model from my research. It is currently configured to train on CUDA enabled devices.

## Setup
1. Ensure all datasets are downloaded and prepared. Instructions for downloading and preparing the datasets used for training the 3D fault detection model can be found [here](../README.md).
